# Codeg UI Bridge 本地测试指南

> v0.2 起扩展直连 Codeg Web 服务，不再需要本地 bridge server 或任何智能体扩展宿主。

## 准备

1. 启动 Codeg 并开启 Web 服务（本例按 `http://127.0.0.1:23080` 配置，端口以实际为准）
2. 记下 Web 服务的访问 Token
3. Codeg 中确认 `pi` 智能体可用（本机已安装 `pi` CLI 或已在 Codeg 中配置）

## 构建扩展

```bash
pnpm install
pnpm build:browser-extension
```

产物在 `packages/browser-extension/dist`。

## 加载扩展

1. Chrome 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 「加载已解压的扩展程序」选择 `packages/browser-extension/dist`

> 开发时可用 `pnpm --filter @codeg-ui-bridge/browser-extension dev` 进入 watch 模式，改完代码在扩展卡片上点刷新。

## 连接 Codeg

1. 点击扩展图标打开 popup
2. 填写 Codeg IP（默认 `127.0.0.1`）、端口（默认 `23080`）、Token
3. 点击「测试连接」，应显示 Codeg 版本号；此时智能体与项目下拉才会加载
4. 智能体下拉只显示已在 Codeg 中启用的条目（附安装状态），两个下拉均支持输入筛选；也可在「手动输入项目路径」里直接填路径
5. 选择该页面所属的项目和用于修改开发的智能体
6. 点击「连接页面」，页面出现 overlay 面板

## 验证完整链路

启动演示项目：

```bash
pnpm dev:react-demo
```

在演示页面上：

1. 面板默认处于选择模式，hover 有蓝色高亮，点击元素出现绿色选中框
2. 若演示项目接入了 source binder，源码绑定区域应显示 `data-codeg-source-*` 对应的文件与行号
3. 在 inline 输入框或面板「修改需求」中输入需求并发送
4. 「执行流」区域应实时出现流式回复、思考摘要与工具调用卡片
5. 若智能体发起权限确认 / 提问 / 计划确认，面板会出现黄色卡片，点击选项直接回应
6. 执行中点击「停止」可取消当前轮次；结束后徽标变为「已完成」
7. 到 Codeg 界面确认产生了对应会话，上下文与本页面请求一致

## 故障排查

- **测试连接失败 / 401 类错误**：检查 Token 是否正确、Codeg Web 服务是否开启
- **连接页面报「请选择项目」**：先在下拉中选择项目或填写手动路径
- **发送后无响应**：确认 Codeg 界面中该会话是否在运行；若提示「上一轮请求仍在执行中」，等待完成或点「停止」
- **长时间空闲后发送失败**：Codeg 默认回收空闲连接，扩展会自动重连并恢复会话历史，重试一次即可
- **执行流无输出但请求成功**：刷新页面后重新连接页面，确认扩展版本已重新构建加载
- **扩展更新后页面无面板**：`chrome://extensions` 刷新扩展后，刷新目标页面
